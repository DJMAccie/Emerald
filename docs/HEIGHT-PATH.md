# Where terrain height comes from (inventory, 2026-10-19)

Read-only survey for the finish-line plan, item 4. Call sites are `~/Documents/battle-art-notquiteog/lib/Gen3Scene.lua` line numbers on 2026-10-19; the order inside Gen3Mass/Gen3Rock (where Gen3Relief and Gen3Hills are called) is not traced yet.

| Module | What it decides | Data it reads / is fed by | Called in Gen3Scene build |
|---|---|---|---|
| `Gen3Elevation` | Floor pin per walkable cell from the cartridge elevation nibble (`COURSE` 16 px); stair claims; props taking the ground under them; foundations of buildings | nibble in map cells; `Gen3EmeraldTerraces` (authored rows), `Gen3StairTerraces` (generated) | `daisPrepare` ~946, `bind` ~966, `daisSettle` ~1077 |
| `TerrainLevels` | Groups floor cells into regions; each group takes the MEDIAN pin of its cells; stair flights between groups; `TerrainLevels.at` for actors and the eye | pins and flights from Gen3Elevation | via Elevation; actors ~1149 |
| `Gen3StairTerraces` | Pins and stair cells for floors the cartridge rates the same level, per map | GENERATED by `tools/elevation/gen_stair_terraces.py` + `height_overrides.json` | read by Gen3Elevation |
| `Gen3EmeraldTerraces` | Authored terrace levels where relief cannot be read from the cartridge | hand-written rows `{anchorX, anchorY, level}` | read by Gen3Elevation |
| `Gen3Mass` / `Gen3Rock` | Rock masses and cliffs rebuilt from their drawing; ledge faces; cave walls | `Gen3RockTables` (generated by `tools/relief/rock_tables.py`) | `Mass.prepare` ~1138, `Mass.append` ~1225 |
| `Gen3Relief` | Counted terrace levels laid on rock cells (5x5 lattice, 4 px steps, 16 px a level) | `Gen3ReliefData` (baked by `tools/relief/bake_lua.py`, port of Emerald 3DS's method) | inside the rock builders |
| `Gen3Hills` | Sand hills on Routes 114/115 as one rolling surface | its own tables | inside the rock builders |
| `Gen3Outdoor` | Ledge geometry and floors around ledges | tile profiles | per cell in append |

## What 2026-10-19 found
- `Gen3StairTerraces.lua` could not be regenerated: a fresh run of the generator differs from the installed file in 12 of its 52 map rows (Frontier East and West, Jagged Pass, Lilycove, Mt. Chimney, Petalburg Woods, Routes 104, 111, 115, 116, 119, 120). Those rows were spliced by hand or tuned after generation.
- Fix (no behaviour change): `tools/elevation/height_overrides.json` holds those 12 rows; `gen_stair_terraces.py` applies it. Check: `GEN_OUT=/tmp/x.lua python3 tools/elevation/gen_stair_terraces.py && python3 tools/elevation/height_overrides.py check /tmp/x.lua` prints `IDENTICAL` (luajit deep comparison of the generated table and the installed one). The installed file was not touched.
- To change a stair height by hand, edit the row in `height_overrides.json` (keep its `why`), regenerate to a scratch path, `check`, then install the output with the usual install protocol.
