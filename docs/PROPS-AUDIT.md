# Props and natural materials audit (2026-10-05)

Scope: everything that is not a building: signs, fences, flowers, shrubs, awnings, boardwalks,
rocks, cliffs, sea boulders, generic objects. Buildings are Opus's (`docs/BUILDINGS-REBUILD.md`).

## Method (repeatable)
```
cd ~/Documents/gen1recomp && luajit ~/Documents/Emerald/tools/props/catalogue_props.lua | tail -n +3 > ~/Documents/Emerald/tools/props/props.tsv
python3 tools/props/audit.py plan sign,fence,shrub,flowers,awning OUT [TOP_N]   # kinds: sign fence shrub flowers awning ledge grass cliff caveWall tree ladder steps OBJECT
EM_WAIT=60 tools/props/audit_capture.sh OUT      # QA identity, player camera; waits for a real game to exit
python3 tools/props/audit.py sheet OUT           # OUT/sheet_NN.png: source art (cell outlined) | game
```
- `catalogue_props.lua` lists every (tileset pair, metatile) that the mod turns into a prop kind, with
  counts and an example cell. `OBJECT` = blocked, unclassified: input of the generic cutter (`Gen3Objects`).
- Long maps (Route 119) need `EM_WAIT=100+` or the shot is blank sky.
- `pgrep -f "MacOS/love"` matches any shell whose command line contains the text, so waiting
  scripts hang or race. Use the exact process name: `pgrep -x love`. A run that logs "update: payload
  handoff failed, reverting to bundled" overlapped another instance: rerun it.

## Trees and foliage (2026-10-06)
- Round trees are closed voxel solids (`VoxelHull`, per-run depth, `NativeTreeArt.TREE_DEPTH=24`); every voxel keeps its sprite pixel. No holes: crowns come from the over layer's exact mask, forest shadow-row drop only in forests, ground-colour cut cannot eat crown pixels.
- Trees on sand/ash/grass/ground (Dewford, Fallarbor, Route 113...) use the ground under them, not a blob.
- Walk-under canopies (Fallarbor, Lavaridge) are raised slabs (`lib/Gen3Canopy.lua`), aligned to the OG at the player camera.
- Tight tree clusters (Mossdeep) are built as one drawing (`Gen3Objects.CLUSTER_CELLS/SPAN`) instead of one cell per object, so each 2-wide tree stays whole.
- Crowns are inflated by distance to the drawing's edge (`VoxelHull.build(...,inflate)`): domed top and sides, flat foot, no flat lid. Cluster trees keep each tree's own crown row (`Gen3Objects` tops rise from every member cell), so Mossdeep's trees are four round trees, not one merged crown and floating canopy slabs.
- Stacked groves (Mossdeep's rocky grove, 34,34): `Gen3Objects.segmentTrees` finds each crown by its lightest highlight (lattice-snapped to the cell grid), lets trees claim pixels front (lowest) first inside their own rounded outline, and builds one round tree per crown (33+13 trees). Falls back to the old per-cell/bank path when the highlights are not on a lattice. Inflated crowns are only 55% as deep behind the middle (`VoxelHull.BACK_RATIO`), stacked trees at most 16 deep (`Gen3Objects.STACK_DEPTH`).
- Inflated crowns keep the drawing's own pixels only on the shell the camera sees (front face, front half of the top); the body behind and beside is the leaf colour of its row (`VoxelHull`, `dominant`), so low and turned views show tiers of leaf, not streaks of outline. Back half 90% as deep, trees up to 28 deep (egg-shaped, not discs).
- Open: nothing known for trees; Fortree canopy stays with Opus.
- Tools: `fourcam.sh` (player / orbit / low / top-down), `foliage_audit.py`, `tree_recipe_check.py`.
