# Emerald 3D

Pokémon Emerald in [gen1recomp](https://github.com/bryanthaboi/gen1recomp) with a voxel overworld and 3D battle models.
This repo holds patches against the upstream mods plus the tools used to build and test them. No game assets.

Licence and provenance: [PROVENANCE.md](PROVENANCE.md). The upstream mod chain declares no
licence, and nothing here re-licenses it.

Start with [HANDOFF.md](HANDOFF.md), then the work queue in [docs/NEXT-AGENT-BRIEF.md](docs/NEXT-AGENT-BRIEF.md).
